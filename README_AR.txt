MeGa SMM — نسخة عربية بواجهة وخلفية وقاعدة بيانات

مهم قبل الاستخدام:
هذه نسخة متجر حقيقية من ناحية التسجيل وتخزين الطلبات وطلبات شحن الرصيد، لكنها لا تتضمن مزود متابعين وهميين ولا تضمن أرقام تفاعل مصطنعة. الخدمات الموجودة هي طلبات حملات ترويج مشروعة وتحتاج تنفيذها يدوياً أو عبر مزود إعلانات متوافق. لا تطلب أبداً كلمة مرور حساب العميل.

المتطلبات: حساب Cloudflare مجاني، وNode.js وWrangler على الكمبيوتر (أو Cloudflare dashboard).

خطوات النشر:
1) فك ضغط الملف.
2) أنشئ قاعدة D1: npx wrangler d1 create mega-smm-db
3) انسخ database_id الذي يظهر وضعه بدلاً من REPLACE_WITH_YOUR_D1_DATABASE_ID في wrangler.toml.
4) أنشئ الجداول: npx wrangler d1 execute mega-smm-db --remote --file=./schema.sql
5) عيّن مفتاح الإدارة: npx wrangler secret put ADMIN_KEY
6) سجّل دخول Cloudflare: npx wrangler login
7) انشر الموقع: npx wrangler deploy

بعد النشر:
- رابط *.workers.dev سيظهر في نتيجة النشر.
- جرّب إنشاء حساب ثم تسجيل الدخول ثم إرسال طلب.
- طلبات العملاء محفوظة في D1 ويمكن إدارتها من API الإدارة الموضح في ADMIN_SETUP.txt.

ملاحظات إنتاج مهمة:
- إعداد وسيلة دفع فعلية يحتاج حساب تاجر/محفظة تجارية ومفاتيح API رسمية. لا تجمع بيانات البطاقات بنفسك.
- غيّر أسعار الخدمات من مصفوفة services داخل src/worker.js.
- واجهة الإدارة المرئية غير مضافة بعد؛ الإدارة الحالية عبر API محمي بمفتاح سري.
- قبل فتحه للجمهور، أضف سياسة خصوصية وشروط استخدام، واختبره، واضبط حدود الطلبات ومكافحة الإساءة.
- Cloudflare وD1 يتطلبان إتمام الإعداد والنشر من حسابك؛ لا أستطيع نشره داخل حسابك دون صلاحية منك.
